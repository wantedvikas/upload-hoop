# Upload Hoop 🏀

A playful file-upload animation: pull a file back like a slingshot, aim, and shoot it into the hoop to "upload" it.
Rim bounces, air balls, a springy net and a +1 Swish. Files you choose or drop stay on your device — nothing is uploaded.

Live: https://wantedvikas.github.io/upload-hoop/

Inspired by a post from @dev_TEMITAYO. Built with plain HTML/CSS/JS + GSAP.
